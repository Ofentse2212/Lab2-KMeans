# K-Means Clustering for Dense Network Data

This project explores how K-Means can reveal structure inside a dense synthetic network of 600 nodes. Each node has a two-dimensional position and an energy value, creating a useful environment for studying clustering, visualisation and the limits of automated grouping.

The work began as an AI practical. I developed it further because clustering is not only a classroom technique: it can support decisions about resource allocation, network monitoring and identifying communities that may need different kinds of support.

## What the project does

1. Generates a reproducible stochastic block-model network
2. Places overlapping communities in a shared coordinate space
3. Assigns an energy value to every node
4. Uses K-Means to group nodes by position
5. Visualises the network, cluster centroids and three-dimensional energy surface

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python kmeans.py
```

The random seed is fixed at `42`, so the experiment is reproducible.

## How to interpret it

K-Means minimises the distance between observations and their assigned centroid. In this experiment it clusters only the `X` and `Y` coordinates; energy is visualised separately. This distinction matters: a visually compelling chart does not prove that energy influenced the model.

The chosen value `k = 7` reflects the seven communities used to generate the synthetic graph. A stronger future version should compare several values using inertia and silhouette score rather than assuming the answer beforehand.

## Limitations

- The dataset is synthetic and should not be treated as evidence about a real community.
- K-Means favours roughly spherical groups and may struggle with irregular network structure.
- Cubic surface interpolation can produce gaps near the boundary of the sampled area.
- Cluster labels are identifiers, not rankings or value judgements.

## Social-impact direction

A responsible extension could use consented, anonymised data to study service demand or infrastructure health. Any real-world use would need privacy safeguards, bias checks and human interpretation before decisions are made.
